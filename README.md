# 日本語→点字変換ライブラリ MOMO

Copyright (c) 2026 MOMO Project Team <seiken@rd01.net>

このプロジェクトは、日本語テキストを点字に変換するライブラリ「MOMO」の開発を目的としています。

日本語点字の変換には、従来、日本語の文法情報を用いて簡単な形態素解析を行い、それを元に点字に変換する方式が採用されてきました。日本語点字を生成するには一般的に以下のようなステップを踏みます。

- 日本語を分かち書きされた仮名に変換します。
  - 原文を形態素解析した品詞リストに展開します。
  - 品詞リストを仮名に変換します。
  - それぞれの品詞感にスペースを入れるべきかどうかを判断します。
- 仮名を点字に変換します。
  - 数字の扱い、アルファベットの扱いなど、特定のルールに従って仮名を点字に変換します。
  - 仮名では書き表せない記号類に関して、特定の点字表現を割り当てます。

それぞれの製品やプロジェクトにより、これらのステップの結合度や実装方法は異なりますが、概ね上記のような要素技術が必要です。

Momoでは、従来型の形態素解析と分かち書きルールを用いた仮名変換に代わって、機械学習を用いた方法を開発しています。

機械学習では、日本語テキストを入力とし、対応する仮名とスペースの有無を出力するモデルを訓練します。これにより、従来のルールベースの方法では捉えきれない微妙なニュアンスや文脈を考慮した変換が可能になります。
また、変換の間違いを修正するのも、実際に間違えた文章と正解を学習させるだけで再学習できるため、辞書のメンテナンスよりも簡単に改善が可能になります。

各サブプロジェクトは、それぞれのサブディレクトリを御覧ください。
