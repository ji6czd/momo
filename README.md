# 自動点訳エンジン Momo

できてきた。3月の花、果物ということで、"Momo"と名付けよう。
…、と書いたのが２０２５年春。そこから１年が経過した。随分形は変わってきたけれど、きっと前に進んでいる。

## 何者？

形態素解析により、文を分解してカタカナに変換して、それを点字に変換します。
初めて自動点訳が試みられたのは1970年代後半のことでした。新聞を自動的に点字にすることが試みられました。
1980年代の後半には、「80点」という自動点訳ソフトウェアが、東北大学を中心に開発されました。
その後いくつかの自動点訳プログラムが開発されました。Extra, Ibuki, Suzuなど。
そして、ここにもう１つ新しいエンジンを加えたいと思います。
形態素解析から、MLを使ったアプローチに進化しました。

## 変換してみる

``` bash
momo translate
```

Sudachiを使った形態素解析で変換します。

``` bash
momo predict --model=dataset/training_data.crfsuite
```

MLを使って変換を行います。

両者とも標準入力からデータを読み込みます。現在変換できそうな文字種については、sample_dataディレクトリを確認してください。

## モデル作成

MLで変換するには、学習データを作成して、モデルを作成する必要があります。学習データは同梱していますので、

``` bash
momo train --tsv=dataset/training_raw.tsv
```

のようにデータを指定して、モデルを作成してください。

## 改造したい人向けに

`translate`コマンドでの処理では、`src/momobrl/proto/braillerules.textproto` ファイルが、分かち書きルールを決めているファイルです。Sudachiお出力を見ながら、品詞との関係を考慮して、間にスペースを入れるのか入れないのかを制御できます。

MLに関しては、`dataset`ディレクトリ以下に私が作成したデータがあります。完全オリジナルの文章です。詳しくは、dataset_raw_rule.mdを見てください。
