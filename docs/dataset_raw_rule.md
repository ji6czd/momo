# 📘 精密点訳データ作成ガイド：RAWデータ記述ルール

このドキュメントは、点訳エンジン学習用のデータ（`training_raw.txt`）を記述するための公式ルールブックです。

## 1. 基本構成

* **フォーマット:** `[原文ブロック群]` + **[TABキー]** + `[読みラベル群]`
* **改行:** 1行につき、1つの意味のある文章（またはフレーズ）を記述。

---

## 2. スラッシュ `/` の掟（一対一対応）

原文と読みは、必ず同じ数の「スラッシュで区切られた塊」で構成されなければなりません。

* **基本:** `平/均` <-> `ヘイ/キン`（ブロック数：2）
* **送り仮名:** 漢字1文字に読みを全乗せする。
* `新/し/い` <-> `アタラ/シ/イ`


* **小書き文字（捨て仮名）:** 2文字で1音となるものは、B/Eタグを意識して分ける。
* `コ/ン/ピ/ュ/ー/タ` <-> `コ/ン/ピュ/---/ー/タ`



---

## 3. 分かち書き（スペース）の表現

点字特有の「分かち書き」部分は、以下のように記述します。

* **ルール:** 原文側は**空（//）**、読み側は**半角スペース（/ /）**とする。
* **例:** `年/齢//八/十` <-> `ネン/レイ/ /8/0`


> **注意:** 読み側のスペースの前後には必ずスラッシュが必要です。



---

## 4. 数字の錬金術（数値化ルール）

数字はTTSや点字数符の処理を容易にするため、半角数字で記述します。

* **基本:** 漢数字は対応する半角数字に置換。
* `二/〇/二/六` <-> `2/0/2/6`


* **位取り（十・百・千など）:**
* **ちょうど0で終わる場合:** `0` を割り当てる。
* `八/十/歳` <-> `8/0/サイ`


* **端数がある場合（スキップ）:** **`_`（アンダースコア）** を割り当てる。
* `二/十/一/日` <-> `2/_/1/ニチ`
* `四/十/三/人` <-> `4/_/3/ニン`





---

## 5. 読みの特別ルール（点字・発音準拠）

視覚的な文字ではなく、**「耳で聞こえる音」**を優先します。

* **助詞の書き換え:**
* は → `ワ`
* へ → `エ`
* を → `オ`


* **長音:**
* 党 → `トー`
* 領 → `リョー`



---

## 6. クイック・サンプル

迷ったらこの1行を思い出してください。

```text
駅/前/の//本/屋/で//二/十/一/日/の//雑/誌/を//買/う/。	エキ/マエ/ノ/ /ホン/ヤ/デ/ /2/_/1/ニチ/ノ/ /ザッ/シ/オ/ /カ/ウ/。

```

---

### 💡 後の自分へのアドバイス

* **「数が合わない！」と怒られたら:** 読み側の半角スペース `/ /` の前後にあるスラッシュを数えてみよう。
* **「文字種不一致」が出たら:** 記号（、や。）の対応がズレていないかチェック。
* **迷ったら:** 1文字1ブロックにバラすのが、最も安全で確実な道。
