## 概要

MomoEditorは、シンプルな点字エディタです。点字のファイルを作成し編集することができます。

## 機能

- 点字ファイルの作成と編集
- テキストファイルを読み込んだ時に自動で点訳する機能
- 基本的なワードラップとフォーマット機能
- ファイルの保存と読み込み
- Unicode点字テキストとBASE形式に対応

## 使用方法

1. スタートメニューに登録されているMomoEditorを起動します。
2. 新しい点字ファイルを作成するには、メニューから「新規作成」を選択します。
3. 既存のテキストファイルを点訳して編集するには、「ファイルを開く」を選択し、テキストファイルを選択します。自動で点訳されます。
4. 編集が完了したら、「保存」または「名前を付けて保存」を選択して、点字ファイルを保存します。
