# Momo: Japanese Text-to-Braille translator for Visual Studio Code

自動点訳エンジンMomoを使って、VS Code上で点訳を行うための拡張機能です。

## Features

- 編集中の行を点訳して、点字表現を表示します。

## Requirements

- 特にありません。
- Momoのインストールは必要ありません。拡張機能内に組み込まれています。

## Extension Settings

特にありません。

## 使い方

以下のコマンドがあります。

- Translate to kana: 編集中の行をカタカナに変換します。
- Translate to braille: 編集中の行を点字に変換します。
- Translate to segmented kana: 編集中の行を分割されたカタカナに変換します。Momoの学習用データを作成するためのコマンドです。
