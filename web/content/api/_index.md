MOMOは外部アプリケーションを開発するためのAPIを提供しています。MOMO APIを使うことで、にほんご→点字変換機能を自分のアプリケーションに組み込むことができます。

APIには以下のものがあります。用途によって使い分けてください。

- Pythonバインディング
- C言語バインディング
- WebAssemblyバインディング

MOMOエディタはC言語バインディングを使って開発されています。Visual Studio拡張はWebAssemblyバインディングを使って開発されています。詳しくはそれぞれのページをごランください。
