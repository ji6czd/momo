MOMOは単体の返還プログラムを提供しています。日常的なファイル変換だけならこれらの単体プログラムを使うのが便利です。

## 変換プログラムの種類

変換プログラムは、Windows GUIと、Windowsコマンドラインの二種類があります。どちらも同じ変換エンジンを使っています。用途に応じて使い分けてください。なお、コマンドライン版のほうが若干マニアックな出力をさせることができます。

## 変換プログラムの使い方

### GUI版の使い方

1. スタートメニューにある「MOMO点字変換」を選択します。
2. ダイアログの指示に従って、変換したいテキストと、返還後のファイル名、ファイル形式を指定してください。変換後のファイルは、指定した場所に保存されます。
3. モデルはLargeモデルを使うことを推奨します。Smallモデルは変換精度が低いので、あまりおすすめしません。
4. OKを押すと、変換が始まります。

### コマンドライン版の使い方

MOMOをインストールすると、momoコマンドにパスが通るようになります。コマンドプロンプトを開いて、
`momo -h`
コマンドを実行してください。使い方が表示されます。

基本的には、

```
momo -i <入力ファイル> -o <出力ファイル> [オプション]
```

のように実行します。出力ファイル名の拡張子によって、出力ファイル形式が自動的に決まります。

- .mbr: MOMO独自形式
- .bse: BASE形式
- .brf: フォーマットされたUnicode点字テキスト
- その他: 仮名テキスト
